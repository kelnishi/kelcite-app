# Changelog Feature Release 0.1.2

Released 2026-02-20.

The **first release**: split and separate meshes, organize them in a scene, move, rotate and scale them, with undo kept across sessions, file import, and 3MF and GLB export.

## Objects and the interface

- First release: split and separate meshes, organize them in a scene, and move, rotate and scale them
- Undo and Redo, kept across sessions, and the scene survives a reload
- Select several objects, use a trackpad or touch screen, and work offline as an installed app

## Files and the tour

Wiki: [Getting Started](Workflow-Getting-Started#the-demo-tour)

- Import by dragging files onto the view, and export to 3MF and GLB
