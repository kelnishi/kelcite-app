# Changelog Feature Release 0.12.13

Released 2026-10-18.

The Asset Library browses **Quaternius and GitHub Sets** models, keeping each asset's license credit, and the toolbar wraps onto more rows.

## Rig and Pose

Wiki: [Rig and Pose a Character](Workflow-Rig-and-Pose-a-Character)

- The Rig tool's Weights tab fits the default panel width, and the humanoid auto-rig opens on the demo's mannequin instead of stopping the app

## Objects and the interface

- The Asset Library browses two more sources of free models: Quaternius's CC0 packs, most of them rigged and animated, and GitHub Sets, with KayKit's CC0 characters and dungeon pieces and sample figures from three.js and Khronos
- An asset from a connector keeps its license credit and a link to its source page, and a failed download says so
- The tool bar wraps its tools onto more rows when they outgrow it, so Apply and Cancel stay in view
