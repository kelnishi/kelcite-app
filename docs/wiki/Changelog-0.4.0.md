# Changelog 0.4.0

Released 2026-03-07.

The **Clay** tool builds editable shapes from blended primitives, tools get plain names, and an on-screen **cheatsheet** shows the shortcuts.

## Clay

Wiki: [Sculpt with Clay](Workflow-Sculpt-with-Clay)

- The Clay tool builds shapes from spheres, boxes, cylinders and other primitives that blend, cut and round, and stay editable until baked; the Bake tool turns clay and modifiers into a mesh

## Objects and the interface

- Tools have plain names: Clay, Move, Pin, Combine, Part and Refine
- An on-screen cheatsheet shows the keyboard shortcuts

## Files and the tour

Wiki: [Getting Started](Workflow-Getting-Started#the-demo-tour)

- Material colors can be customized and are kept through import and export, with new rendering modes
