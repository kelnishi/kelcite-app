# Changelog 0.8.1

Released 2026-04-03.

**SVGs** are their own kind of node, the **Text** tool makes text from Markdown, **SVG decals** project onto meshes, and 3MF export writes face colors Bambu Studio reads.

## Paint

Wiki: [Paint Decals and Texture Maps](Workflow-Paint-Decals-and-Texture-Maps)

## Objects and the interface

- SVGs are their own kind of node in the scene, and the Text tool makes text from Markdown as an SVG

## Files and the tour

Wiki: [Getting Started](Workflow-Getting-Started#the-demo-tour)

- Face group colors map to filaments in 3MF files, and 3MF export writes face colors that Bambu Studio reads
