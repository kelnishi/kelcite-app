# Changelog 0.12.26

Released 2026-10-19.

A **tool search** beside Undo and Redo lists every tool with its key and finds tools and commands by name.

## Objects and the interface

- The search button beside Undo and Redo lists every tool with its icon and key, and finds tools and commands by name, by a former name or by what they do. ⌘K or Ctrl+K opens it
- When a search narrows to one result, its tool icon or button is outlined, with the tool's tooltip open; Escape clears the search, then closes the menu
- The keyboard cheatsheet no longer lists the tools' keys, which the search shows. The demo tour has a Search stop
