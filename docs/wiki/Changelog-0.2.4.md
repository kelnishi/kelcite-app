# Changelog 0.2.4

Released 2026-03-01.

A **light and dark theme**, local transforms in Move, and an undo history you can export.

## Move

Wiki: [Construction and Rigging](Tool-Construction-and-Rigging#move)

- Move shows local positions and scales, and copies and pastes transforms as text

## Objects and the interface

- A light and dark theme toggle in the toolbar, and the ground grid no longer flickers
- Tab cycles through pivot points, and paste places nodes beside or inside the selection
- Undo history describes each step, and can be exported as a file
